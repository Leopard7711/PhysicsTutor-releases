# 물리 튜터 (PhysicsTutor)

Claude AI가 1:1로 대학 물리(일반물리와 2학년 전공)를 가르쳐 주는 Windows 데스크톱 앱입니다. 개인이 만든 무료 앱이에요.

- **일반물리 4과목**: 역학, 파동과 열, 전자기학, 현대물리 기초
- **대학 2학년 4과목**: 고전역학(라그랑주·해밀턴), 전자기학(벡터 해석, 맥스웰 방정식), 양자역학, 열·통계물리
  (모두 MIT OCW 강의 구성을 참고한 진도표)
- **앱이 그리는 그림**: 자유물체도(빗면, 도르래, 용수철, 전하, 전기장·자기장), 회로도, x-t·v-t·a-t 운동 그래프, 원 궤도·각도·과정 흐름도 같은 설명 그림.
  힘의 방향과 각도를 앱이 계산해서 정확하게 그려요
- **검산**: 튜터가 낸 식의 단위(차원)가 맞는지, 질량 0·각도 90° 같은 극단적인 경우에도 말이 되는지를 앱이 직접 확인해요
- **부호와 좌표 기준**: 풀이마다 좌표 기준을 먼저 정하고 끝까지 유지해요. 흔한 오개념은 반례로 짚어 줘요
- **채점**: 숫자 답(유효숫자 차이 허용, 단위를 붙여 써도 됨)과 기호 답(m*g*sin(theta) 같은 식)을 자동 채점해요
- **설명 검토**: 긴 설명은 보여 주기 전에 다른 AI가 한 번 더 읽고, 틀린 문장이나 빠진 조건을 고쳐서 보여 줘요
- **개념집**: 한 번 유도한 공식과 정리한 개념을 설명할 때 그린 그래프·그림과 함께 저장해 두고 다시 꺼내 써요(검증됨 표시). 그림 없는 항목은 '그래프 그리기'로 붙일 수 있어요. 공식을 누르면 유도가 펼쳐지고,
  **꼭 알아야 해요 / 알면 좋아요 / 몰라도 돼요**로 나눠 꼭 필요한 것만 펼쳐 보여 줘요. 과정과 상관없는 질문은 '과정 밖 질문'에 따로 모아요
- **사진으로 묻기**: 📷 버튼이나 붙여 넣기(Ctrl+V)로 문제·손으로 쓴 풀이 사진을 보내면 읽고 어디서 틀렸는지 짚어 줘요
- **예제 풀이 접기**: 예제의 풀이는 접혀 있어서 먼저 풀어 본 뒤 펼쳐 볼 수 있어요
- **복습**: 주제별 간격 반복, 오답노트(변형 문제), 시험 모드(범위·문항 수·난이도·시간)
- **구글 계정 동기화(선택)**: 여러 PC에서 진도와 대화를 이어 가기

## 받기

**[최신 버전 내려받기 (PhysicsTutor.exe)](https://github.com/Leopard7711/PhysicsTutor-releases/releases/latest/download/PhysicsTutor.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 새 버전이 나오면 앱이 켜질 때 알아서 업데이트해요.
- **이 페이지(github.com/Leopard7711/PhysicsTutor-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다. 백신이 막으면 이 페이지에서 받은 파일인지 확인한 뒤 예외로 허용해 주세요.

## 처음 시작: API 키 넣기

이 앱은 AI 사용료를 **본인의 Anthropic(또는 OpenAI) 계정에서 직접** 내는 방식이에요(개발자에게 가는 돈은 없어요).

- **Claude (기본)**: https://console.anthropic.com 가입 → **Billing**에서 크레딧 충전 → **API Keys** → **Create Key**로 키(`sk-ant-…`)를 만들어 복사
- **GPT**: https://platform.openai.com 가입 → 결제 등록·크레딧 충전 → **API keys**에서 키(`sk-…`)를 만들어 복사

앱을 처음 켜면 나오는 창에 붙여 넣으면 끝. 어느 회사 키인지는 앱이 알아봐요. 키는 이 PC에만 저장되고 동기화하지 않아요.

## 비용은 얼마나?

앱 아래 상태줄에 이번 세션과 누적 비용(추정)이 늘 표시돼요. 설정에서 모델을 바꿀 수 있어요.

| 모델 | 특징 | 대략적인 비용 |
|---|---|---|
| Sonnet (기본) | 일반물리 설명과 문제 풀이에 충분 | 공부 1시간에 약 $1 |
| Opus | 가장 깊고 정확함. 어려운 문제에 | 약 2배 |
| Haiku | 복습·연습·짧은 질문용 | 훨씬 저렴 |
| GPT-6.1 Sol / Terra | OpenAI 키로 쓰는 중간·저가 모델 | Sonnet보다 조금 싸거나(Sol) 절반(Terra) |

어려운 문제만 Opus로 풀고 싶으면 입력칸 위의 **🧠 이번 질문만 Opus**를 켜고 보내세요(그 질문 하나만 Opus로 답해요).
실제 비용은 질문 길이와 양에 따라 달라요. 긴 대화를 오래 쉬었다가 이어 가면 첫 답이 비싸지는데, 그럴 땐 앱이 "새로 시작 / 이어 가기"를 먼저 물어봐요.
새로 시작할 때 "지난 대화 이어서"를 고르면 지난 대화를 짧게 요약해 넘겨서(약 1센트) 하던 데부터 이어 가요.
